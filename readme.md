# ArcDraw

**Windows 화면 필기와 독립적인 화이트보드 노트를 함께 사용하는 앱입니다.**
ppInk/gInk를 바탕으로 노트별 텍스트, CAPS 입력 전환, 툴바 테마 등을 추가했습니다.

**[Windows 실행 ZIP 다운로드](https://github.com/gamzagui-collab/ArcDraw/releases/latest/download/ArcDraw-v0.20-windows-x86.zip)** · [릴리스 안내](https://github.com/gamzagui-collab/ArcDraw/releases)

## 실행 방법

1. 위 실행 ZIP을 내려받아 새 폴더에 **모두 압축 해제**합니다.
2. 같은 폴더의 **ArcDraw.exe**를 실행합니다. EXE 이름은 ArcDraw에서도 그대로 사용합니다.
3. 화면의 ArcDraw 아이콘을 누르고 **Caps Lock을 켜면** 그릴 수 있습니다.

필요 환경은 Windows 데스크톱과 .NET Framework 4.8입니다. 기존 ppInk 설치 폴더와 분리해서 실행하세요. 시스템 DLL을 교체할 필요는 없습니다.

## 주요 기능

- 화면 펜·지우개와 별개로 사용하는 여러 화이트보드 노트
- 노트별 한글·영문 메모장 입력과 이름 변경
- 노트 이동, 모서리 크기 조절, 개별 숨김·표시·삭제·세로/가로 정렬
- 화면과 노트에서 사용하는 도형·선 모양 프리셋
- 선택한 화면 또는 노트에 적용되는 삭제·실행 취소·다시 실행
- 10개 툴바 테마와 가로 1줄·가로 2줄·세로 배치, 크기 조절
- 접힌 툴바에서도 CAPS 상태 표시, 필기 대상에 따라 옮겨지는 얇은 네온 테두리

## 기본 조작

| 조작 | 동작 |
| --- | --- |
| Caps Lock ON / OFF | 그리기·툴바 펼치기 / 일반 조작·자동 접기 |
| 점 6개 이동 블록 | ON/OFF 상태 모두 툴바 이동 |
| Tab (CAPS ON) | 툴바 접기·펼치기 |
| Alt 누르고 있기 | 도구별 단축키 표시 |
| Alt+Tab (CAPS ON) | 화면·노트 순환, Alt 놓아 확정, Esc 취소 |
| Delete (CAPS ON) | 현재 선택 대상의 마지막 작업 실행 취소 |
| Ctrl+Delete (CAPS ON) | 현재 선택 대상 전체 삭제 |
| Ctrl+Shift+Z | 다시 실행 |
| 1~0 (저장한 프리셋) | 색·굵기·펜촉·도구 불러오기 |
| 세로 정렬 / 가로 정렬 | 표시 중인 노트 겹침 없이 정렬 |
| ⚙ 설정 | 프리셋·글꼴·테마 설정 |
| T | 텍스트 도구 |
| Enter (노트 메모) | 다음 줄 |
| Ctrl+Enter / Esc (노트 메모) | 내용 유지 후 편집 마침 |
| Esc (그리기 중) | 노트를 숨기고 아이콘으로 복귀; 다시 켜면 복원 |

화면 또는 노트를 선택한 뒤 삭제·실행 취소를 사용하세요. 노트를 선택한 뒤 T로 상단부터 메모합니다. 기존 배치 글자는 제목 우클릭에서 편집하며 제목 옆 ✎로 이름을 바꿉니다.

## v0.20 변경과 확인 범위

- **노트 이름 변경:** 제목 옆 **✎** 또는 제목/툴바 목록 우클릭에서 변경합니다. 제목·툴바·Alt+Tab 목록이 같은 이름을 표시하며 한글과 `&` 같은 문자도 그대로 표시합니다.
- **Alt+Tab 창 잔류/멈춤 수정:** 전환 목록이 노트를 자동 활성화하는 것을 사용자 선택으로 오인해 취소하던 경로를 수정했습니다. 입력 작업을 직렬 처리하고 실제 키 해제와 창 표시 상태를 확인하여, 키를 놓고 남은 창이나 누락된 Tab-up 상태를 복구합니다. Alt를 누른 채 Tab을 떼었다 누르면 다음 항목으로, Alt를 놓으면 확정하고 닫힙니다.
- **노트 메모장 모드:** 노트를 선택하고 **T**를 누르면 좌측 상단부터 노트 전체에 입력합니다. **Enter는 다음 줄**입니다. 펜 버튼으로 돌아오면 내용을 유지하고 필기를 이어갑니다. 메모의 Ctrl+Enter/Esc는 내용을 유지하며 편집을 마칩니다.
- 기존에 위치를 지정한 글자는 유지하며 제목 우클릭의 **기존 배치 글자 편집**에서 수정합니다. 노트 메모와 원래의 화면 텍스트 도구는 분리되어 있습니다.
- 정렬 버튼 문구를 **세로 정렬 / 가로 정렬**로 변경했습니다.

Windows Release|x86 빌드 통과. 별도 Windows 검사본이 빌드 EXE의 Root/Forms를 호스팅하여 해제 후 남은 창의 복구, 빠른 Alt+Tab 입력, 실제 Alt 유지·Tab 반복·해제, 실제 이름 편집 버튼과 세 목록 반영, Unicode 한글 입력/실제 Enter 줄바꿈, 첫 펜 버튼 클릭 후 저장·필기 복귀, CAPS OFF 확정과 같은 프로세스 재진입 보존을 확인했습니다. 마지막 표시/복구 보정 후 그 영향 부분만 검사했으며 통과한 흐름을 반복하지 않았습니다.

물리 한글 IME 조합 자체, 전체 회귀·장시간 반복, 게임 독점 전체화면 및 다양한 고DPI·멀티 모니터는 이번 검증 범위에 포함하지 않았습니다. 노트 이름·내용의 유지 범위는 기존 노트와 같이 **현재 실행 중 ESC/재진입**이며, 완전 종료 후 노트 자동 저장을 추가한 것은 아닙니다. 기존 설정과 이전 릴리스를 보존하며 시스템 DLL을 변경하지 않습니다.

자세한 사용법은 [설정 안내](docs/SETTINGS_KO.md)를 참고하세요.
