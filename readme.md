# ArcDraw

**Windows 화면 필기와 독립적인 화이트보드 노트를 함께 사용하는 앱입니다.**
ppInk/gInk를 바탕으로 노트별 텍스트, CAPS 입력 전환, 툴바 테마 등을 추가했습니다.

**[Windows 실행 ZIP 다운로드](https://github.com/gamzagui-collab/ArcDraw/releases/latest/download/ArcDraw-v0.19-windows-x86.zip)** · [릴리스 안내](https://github.com/gamzagui-collab/ArcDraw/releases)

## 실행 방법

1. 위 실행 ZIP을 내려받아 새 폴더에 **모두 압축 해제**합니다.
2. 같은 폴더의 **ArcDraw.exe**를 실행합니다. EXE 이름은 ArcDraw에서도 그대로 사용합니다.
3. 화면의 ArcDraw 아이콘을 누르고 **Caps Lock을 켜면** 그릴 수 있습니다.

필요 환경은 Windows 데스크톱과 .NET Framework 4.8입니다. 기존 ppInk 설치 폴더와 분리해서 실행하세요. 시스템 DLL을 교체할 필요는 없습니다.

## 주요 기능

- 화면 펜·지우개와 별개로 사용하는 여러 화이트보드 노트
- 노트별 한글·영문·여러 줄 텍스트 입력 및 수정
- 노트 이동, 모서리 크기 조절, 개별 숨김·표시·삭제·세로/가로 정렬
- 화면과 노트에서 사용하는 도형·선 모양 프리셋
- 선택한 화면 또는 노트에 적용되는 삭제·실행 취소·다시 실행
- 10개 툴바 테마와 가로 1줄·가로 2줄·세로 배치, 크기 조절
- 접힌 툴바에서도 CAPS 상태 표시, 필기 대상에 따라 옮겨지는 얇은 네온 테두리

## 기본 조작

| 조작 | 동작 |
| --- | --- |
| Caps Lock ON / OFF | 그리기·툴바 펼치기 / 일반 조작·자동 접기 |
| 점 6개 이동 블록 | ON/OFF 상태 모두 툴바 이동 |
| Tab (CAPS ON) | 툴바 접기·펼치기 |
| Alt 누르고 있기 | 도구별 단축키 표시 |
| Alt+Tab (CAPS ON) | 화면·노트 순환, Alt 놓아 확정, Esc 취소 |
| Delete (CAPS ON) | 현재 선택 대상의 마지막 작업 실행 취소 |
| Ctrl+Delete (CAPS ON) | 현재 선택 대상 전체 삭제 |
| Ctrl+Shift+Z | 다시 실행 |
| 1~0 (저장한 프리셋) | 색·굵기·펜촉·도구 불러오기 |
| 좌측 세로 / 상단 가로 | 표시 중인 노트 겹침 없이 정렬 |
| ⚙ 설정 | 프리셋·글꼴·테마 설정 |
| T | 텍스트 도구 |
| Ctrl+Enter / Esc (노트 텍스트 편집 중) | 확정 / 취소 |
| Esc (그리기 중) | 노트를 숨기고 아이콘으로 복귀; 다시 켜면 복원 |

화면 또는 노트를 선택한 뒤 삭제·실행 취소를 사용하세요. 노트 텍스트를 수정할 때에는 T 도구로 기존 글자를 누릅니다.

## v0.19 변경과 확인 범위

- **필기 대상에만 네온 테두리**를 표시합니다. 처음 화면을 선택한 상태에서는 화면에, 노트를 클릭/선택하거나 필기하면 해당 노트에만 표시합니다. 화면에 다시 필기하면 화면으로 돌아갑니다.
- 선택 노트의 이동·크기 변경에 즉시 따라갑니다. 기존의 얇고 클릭을 통과하는 네 개 테두리 창을 재사용하며, 단순 이동 때 비트맵을 다시 만들지 않습니다.
- **CAPS ON에서 Alt를 누른 채 Tab을 반복**하면 화면과 노트 목록을 순환합니다. **Alt를 놓으면 선택 확정**, **Esc는 전환 취소**입니다. 숨긴 노트도 목록에서 선택하면 다시 표시됩니다.
- CAPS OFF·텍스트 편집·설정 창에서는 기존 Windows Alt+Tab 처리 경로를 유지합니다. 설정을 열거나 그리기를 종료하면 전환 목록을 취소합니다. 노트 텍스트 편집 중에도 선택 노트의 테두리는 유지합니다.

Windows Release|x86 빌드 통과. 별도 Windows 검사본이 빌드 EXE의 Root/Forms를 호스팅하여 실제 마우스 필기로 화면→노트1→노트2→화면의 선택/테두리 전환, 노트 이동·크기 변경과 테두리 창 재사용을 확인했습니다. 실제 Alt 유지·Tab 반복·Alt 해제로 노트 전환/숨긴 노트 복원, Esc 취소를 확인했습니다.

CAPS OFF와 텍스트 편집 중 Tab의 전달은 뒤쪽 검사 훅에서 확인했으며, 다른 사용자 앱으로 넘어가지 않도록 검사 훅에서 소비했습니다. Windows 전환 UI 자체를 검사한 것은 아닙니다. 주입된 Shift 조합에 대한 환경 제약으로 선택적 역방향(Alt+Shift+Tab)은 정확한 훅 이벤트 재생만 확인했으며 물리 역방향 검증을 주장하지 않습니다. 마지막 안내/번호 배치와 설정 창 진입 취소 보정 후 해당 부분만 다시 검사했습니다.

전체 회귀·장시간 반복, IME·단축키 전체, 게임 독점 전체화면 및 다양한 고DPI·멀티 모니터 환경은 이번 검증 범위에 포함하지 않았습니다. 기존 필기·프리셋·정렬 데이터 경로와 시스템 DLL은 변경하지 않았습니다.

자세한 사용법은 [설정 안내](docs/SETTINGS_KO.md)를 참고하세요.
