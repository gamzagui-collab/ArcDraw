# ArcDraw

**Windows 화면 필기와 독립적인 화이트보드 노트를 함께 사용하는 앱입니다.**
ppInk/gInk를 바탕으로 노트별 텍스트, CAPS 입력 전환, 툴바 테마 등을 추가했습니다.

**[Windows 실행 ZIP 다운로드](https://github.com/gamzagui-collab/ArcDraw/releases/latest/download/ArcDraw-v0.18-windows-x86.zip)** · [릴리스 안내](https://github.com/gamzagui-collab/ArcDraw/releases)

## 실행 방법

1. 위 실행 ZIP을 내려받아 새 폴더에 **모두 압축 해제**합니다.
2. 같은 폴더의 **ArcDraw.exe**를 실행합니다. EXE 이름은 ArcDraw에서도 그대로 사용합니다.
3. 화면의 ArcDraw 아이콘을 누르고 **Caps Lock을 켜면** 그릴 수 있습니다.

필요 환경은 Windows 데스크톱과 .NET Framework 4.8입니다. 기존 ppInk 설치 폴더와 분리해서 실행하세요. 시스템 DLL을 교체할 필요는 없습니다.

## 주요 기능

- 화면 펜·지우개와 별개로 사용하는 여러 화이트보드 노트
- 노트별 한글·영문·여러 줄 텍스트 입력 및 수정
- 노트 이동, 모서리 크기 조절, 개별 숨김·표시·삭제·세로/가로 정렬
- 화면과 노트에서 사용하는 도형·선 모양 프리셋
- 선택한 화면 또는 노트에 적용되는 삭제·실행 취소·다시 실행
- 10개 툴바 테마와 가로 1줄·가로 2줄·세로 배치, 크기 조절
- 접힌 툴바에서도 CAPS 상태 표시, 그리기 상태의 얇은 화면 테두리

## 기본 조작

| 조작 | 동작 |
| --- | --- |
| Caps Lock ON / OFF | 그리기·툴바 펼치기 / 일반 조작·자동 접기 |
| 점 6개 이동 블록 | ON/OFF 상태 모두 툴바 이동 |
| Tab (CAPS ON) | 툴바 접기·펼치기 |
| Alt 누르고 있기 | 도구별 단축키 표시 |
| Delete (CAPS ON) | 현재 선택 대상의 마지막 작업 실행 취소 |
| Ctrl+Delete (CAPS ON) | 현재 선택 대상 전체 삭제 |
| Ctrl+Shift+Z | 다시 실행 |
| 1~0 (저장한 프리셋) | 색·굵기·펜촉·도구 불러오기 |
| 좌측 세로 / 상단 가로 | 표시 중인 노트 겹침 없이 정렬 |
| ⚙ 설정 | 프리셋·글꼴·테마 설정 |
| T | 텍스트 도구 |
| Ctrl+Enter / Esc (노트 텍스트 편집 중) | 확정 / 취소 |
| Esc (그리기 중) | 노트를 숨기고 아이콘으로 복귀; 다시 켜면 복원 |

화면 또는 노트를 선택한 뒤 삭제·실행 취소를 사용하세요. 노트 텍스트를 수정할 때에는 T 도구로 기존 글자를 누릅니다.

## v0.18 변경과 확인 범위

- **노트 안에서도 저장한 프리셋의 도형·선 모양을 사용**합니다. 직선·사각형·원/타원·시작/끝 화살표·연속선·자유펜과 실선·파선·점선·일점쇄선·이점쇄선을 지원합니다. 색·굵기·불투명도·도형 채움도 연동합니다.
- 노트의 지우개·실행 취소/다시 실행과 같은 Ink 데이터에 저장하므로 노트 이동과 같은 프로세스의 ESC 재진입에서도 유지합니다. 연속선은 이어 클릭/드래그하며 우클릭으로 마칩니다. 프리셋을 바꾸면 이전 선은 보존하고 새 연속선을 시작합니다.
- 노트 카드에 **좌측 세로 / 상단 가로** 정렬 버튼을 추가했습니다. 표시 중인 노트를 생성 순서대로, 툴바가 있는 화면의 작업 영역에 배치합니다. 세로는 위→아래 후 다음 열, 가로는 왼쪽→오른쪽 후 다음 행으로 이어집니다.
- 노트 크기·내용을 유지하고 겹치지 않게 배치합니다. 숨긴 노트는 이동하지 않습니다. 공간이 부족하면 안내하고 기존 배치를 유지합니다.
- 일반 자유펜·지우개의 native Ink 경로와 원본 화면 수집·렌더링 경로는 유지합니다. 입력 시작은 메시지를 처리할 수 있는 Ink 호출보다 앞서 초기화하고, 도형 미리보기는 노트 내부의 변경 영역에 그립니다.

Windows Release|x86 빌드 통과. 별도 Windows 검사본이 빌드 EXE의 Root/Forms를 호스팅하여 실제 마우스와 숫자키로 노트 도형·선 모양·점선 간격·지우개·실행 취소/다시 실행·일반 자유펜 복귀를 확인했습니다. 네 개 노트의 두 정렬 방향, 다음 열/행 전환, 겹침/화면 경계, 내용/크기/숨긴 노트 유지, 불가능한 배치 계산 거부, 같은 프로세스 재진입을 확인했습니다.

캡처 확인 후 입력 시작 순서를 보강하고 최종 빌드에서 드래그 끝점과 저장 좌표 일치 및 연속선 프리셋 전환만 다시 검사했습니다. 통과한 정렬 검사를 반복하지 않았습니다. Program.Main 전체 회귀·장시간 반복 검사는 아닙니다. 물리 펜/터치/필압, 실제 IME와 전역 단축키 전체, 게임 독점 전체화면 및 다양한 고DPI·멀티 모니터 환경은 이번 검증 범위에 포함하지 않았습니다.

자세한 사용법은 [설정 안내](docs/SETTINGS_KO.md)를 참고하세요.
