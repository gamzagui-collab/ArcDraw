# ArcDraw

**Windows 화면 필기와 독립적인 화이트보드 노트를 함께 사용하는 앱입니다.**
ppInk/gInk를 바탕으로 노트별 텍스트, CAPS 입력 전환, 툴바 테마 등을 추가했습니다.

**[Windows 실행 ZIP 다운로드](https://github.com/gamzagui-collab/ArcDraw/releases/latest/download/ArcDraw-v0.25-windows-x86.zip)** · [릴리스 안내](https://github.com/gamzagui-collab/ArcDraw/releases)

## 실행 방법

1. 위 실행 ZIP을 내려받아 새 폴더에 **모두 압축 해제**합니다.
2. 같은 폴더의 **ArcDraw.exe**를 실행합니다. EXE 이름은 ArcDraw에서도 그대로 사용합니다.
3. 화면의 ArcDraw 아이콘을 누르고 **Caps Lock을 켜면** 그릴 수 있습니다.

필요 환경은 Windows 데스크톱과 .NET Framework 4.8입니다. 기존 ppInk 설치 폴더와 분리해서 실행하세요. 시스템 DLL을 교체할 필요는 없습니다.

## 주요 기능

- 화면 펜·지우개와 별개로 사용하는 여러 화이트보드 노트
- 노트별 한글·영문 메모장 입력·이름 변경·글꼴 설정과 자동저장/재시작 복원
- 노트 이동, 모서리 크기 조절, 개별 숨김·표시·삭제·세로/가로 정렬
- 화면과 노트에서 사용하는 도형·선 모양 프리셋
- 선택한 화면 또는 노트에 적용되는 삭제·실행 취소·다시 실행
- 10개 툴바 테마와 가로 1줄·가로 2줄·세로 배치, 크기 조절
- 접힌 툴바에서도 CAPS 상태 표시, 필기 대상에 따라 옮겨지는 얇은 네온 테두리

## 기본 조작

| 조작 | 동작 |
| --- | --- |
| Caps Lock ON / OFF | 그리기·툴바 펼치기·노트 복원 / 일반 조작·자동 접기·모든 노트 숨김 |
| 점 6개 이동 블록 | ON/OFF 상태 모두 툴바 이동 |
| Tab (CAPS ON) | 툴바 접기·펼치기 |
| Alt 누르고 있기 | 도구별 단축키 표시 |
| Alt+Tab (CAPS ON) | 화면·노트 순환, Alt 놓아 확정, Esc 취소 |
| Delete (CAPS ON) | 현재 선택 대상의 마지막 작업 실행 취소 |
| Ctrl+Delete (CAPS ON) | 현재 선택 대상 전체 삭제 |
| Ctrl+Shift+Z | 다시 실행 |
| 1~0 (저장한 프리셋) | 색·굵기·펜촉·도구 불러오기 |
| 노트 이름 / 옆 ●·□ / × | 선택 / 표시·숨김 / 해당 노트 삭제 |
| 세로 정렬 / 가로 정렬 | 표시 중인 노트 겹침 없이 정렬 |
| ⚙ 설정 | 프리셋·글꼴·테마 설정 |
| T | 텍스트 도구 |
| Enter (노트 메모) | 다음 줄 |
| Ctrl+Enter (노트 메모) | 내용 유지 후 편집 마침 |
| Esc (노트 메모·CAPS ON/OFF) | 내용 유지 후 앱 아이콘 복귀 |
| Esc (그리기 중) | 노트를 숨기고 아이콘으로 복귀; 다시 켜면 복원 |

화면 또는 노트를 선택한 뒤 삭제·실행 취소를 사용하세요. 노트를 선택한 뒤 T로 상단부터 메모합니다. 기존 배치 글자는 제목 우클릭에서 편집하며 제목 옆 ✎로 이름과 해당 노트 메모의 글꼴·크기·색상을 바꿉니다.

## v0.25 변경과 확인 범위

- **메모→화면 드래그 멈춤 수정:** 노트 T 상태가 화면으로 전달되어 투명한 화면 텍스트 모달이 열리던 현상을 재현하고 수정했습니다. 메모 입력 후 화면을 바로 드래그하면 직전 화면 그리기 도구로 돌아가며 첫 획부터 그립니다.
- 창의 자동 활성화를 노트 선택으로 처리하던 경로를 제거했습니다. 실제 클릭과 전환 목록에서 고른 대상을 따릅니다.
- 같은 노트를 다시 선택하면 메모를 이어 쓸 수 있습니다. 노트에서 펜/도형을 쓰려면 해당 도구를 선택합니다. 화면에서 명시적으로 T를 고르는 기존 텍스트 입력도 유지합니다.
- 새 UI 기능과 저장 형식 변경 없이 입력 전환에 집중한 수정입니다.

Windows Release|x86 빌드 통과. 격리된 v0.24에서 사용자 순서와 같은 투명 모달/입력 중단/Esc 후 노트 재진입을 실제 마우스로 재현했습니다. 수정 후 메모→화면 첫 획→노트 메모 복귀→명시적 펜→화면 필기와 기존 화면 T/취소 복귀를 확인했습니다. 자동 활성화 문제를 추가 보정한 뒤 영향받은 전환 흐름만 재검사했으며 전체 검사는 반복하지 않았습니다.

물리 IME 조합 자체, 모든 도형·클립아트 조합, 전체 회귀·장시간 성능, 게임 독점 전체화면 및 다양한 고DPI·멀티 모니터는 이번 검증 범위에 포함하지 않았습니다. 기존 설정·개인 노트·이전 릴리스와 자동저장 형식은 보존하며 시스템 DLL을 변경하지 않습니다.

자세한 사용법은 [설정 안내](docs/SETTINGS_KO.md)를 참고하세요.
