ppInk v0.4 — 테마 10종 / 슬림 툴바

실행: 바탕화면 「ppInk 최신본」
변경: 필기 세션의 「모양」 → 테마 / 크기 / 배치 → 적용

테마 10종: 페이퍼 바, 미드나이트, 소프트 크림, 모노라인, 스튜디오 패널,
네온 도크, 세로 레일, 분리형 포드, 블루 글래스, 라벨 리본.
기존 기본·라이트도 그대로 선택할 수 있습니다.
시안의 색상·모서리·버튼 간격·라벨을 기존 ppInk 아이콘과 결합했습니다.

배치: 가로 한 줄 / 세로 두 열. 모든 테마에서 별도로 선택합니다.
가로는 도구와 레이어 바가 같은 높이에 이어집니다. 노트가 많으면 ⋯에서
전체 노트의 선택·표시·숨김·삭제를 할 수 있습니다.
세로는 도구를 두 열에 놓고, CAPS·노트 제어를 아래에 이어 붙입니다.
100% 기준 도구 버튼 34픽셀, 가로 전체 높이 약 42픽셀.
50~150% 크기 옵션은 유지하며 화면 공간에 맞게 버튼 크기를 제한합니다.
라벨 리본은 한 줄 높이를 유지하기 위해 아이콘 옆에 이름을 표시합니다.
펜 색상 아이콘은 원래 색을 유지합니다.

기존 Caps / Tab / Shift+Delete / Ctrl+Delete 기능은 그대로 사용합니다.
테마·크기·배치는 toolbar-ui.ini에 저장됩니다. 이전 설정에 Layout이 없으면
가로 한 줄을 사용합니다. 기존 사용자 테마 파일도 유지됩니다.

추가 *.ini 색상 테마: Name / Background / Surface / Text / Accent 항목을 사용합니다.
