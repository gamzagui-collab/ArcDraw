# ArcDraw 단축키

[홈으로](../README.md) · [사용설명서](USER_GUIDE_KO.md) · [버전별 변경 사항](../CHANGELOG.md)

아래는 기본 배포 설정입니다. 도구 단축키는 **Caps Lock을 켠 그리기 상태**에서 사용합니다. 툴바에서 **Alt**를 누르고 있으면 현재 설정된 키를 확인할 수 있습니다.

## 앱과 작업 대상

| 키 | 동작 |
| --- | --- |
| Ctrl+Alt+G | 전역 그리기 단축키. 툴바를 열거나 포인터와 그리기 상태를 전환합니다. |
| Ctrl+F4 | 화면 액자 켜기/끄기. 툴바를 닫은 상태에서도 동작합니다. |
| Ctrl+Shift+B | 새 화이트보드 노트를 엽니다. |
| Ctrl+Shift+H | 현재 노트를 표시하거나 숨깁니다. |
| Caps Lock | 켜면 그리기와 노트 조작, 끄면 일반 포인터 조작과 노트 임시 숨김으로 전환합니다. |
| 휠 버튼 클릭·드래그 | Caps Lock을 켠 채 일반 왼쪽 클릭 또는 창 이동을 합니다. |
| Tab | 그리기 중 툴바를 접거나 펼칩니다. |
| Alt+Tab | 그리기 중 화면과 노트 목록을 순환합니다. Alt를 놓으면 선택한 대상으로 이동합니다. |
| Esc | 그리기나 노트 입력을 마치고 ArcDraw 아이콘으로 돌아갑니다. 대상 선택 목록에서는 선택을 취소합니다. |

## 그리기

| 키 | 동작 |
| --- | --- |
| P / B / L / R / O / A | 자유펜 / 속도 붓 / 직선 / 사각형 / 원·타원 / 화살표 |
| T / E / C | 텍스트 / 지우개 / 클립아트 |
| N / M / Q | 번호표 / 편집 / 올가미 선택 |
| H / S / Z | 이동 / 확대·회전 / 돋보기 |
| ` / V / K / D | 필기 표시·숨기기 / 색 추출 / 화면 캡처 / 선 모양 전환 |
| Ctrl+Shift+S / Ctrl+Shift+L | 필기 저장 / 필기 열기 |
| 숫자키 1–0 | 저장된 펜 프리셋을 선택합니다. |
| ← / → | 자유펜·직선·도형·화살표·지시선 텍스트·연속선과 텍스트 도구는 설정한 빠른 색상을 이전/다음 순서로, 클립아트 도구는 사용 횟수로 정렬된 목록에서 이전/다음 클립아트를 고릅니다. 텍스트 입력창이 열려 있으면 커서를 이동합니다. |
| Delete / Ctrl+Z / Ctrl+Shift+Z | 그리기 실행 취소 / 실행 취소 / 다시 실행 |
| Ctrl+Delete | 선택한 대상의 필기를 모두 지웁니다. 노트 메모는 보존합니다. |
| Ctrl+클릭 / Ctrl+드래그 | 그린 선·도형·클립아트·텍스트를 선택하고 이동합니다. |
| 휠 | 선 굵기, 클립아트 크기 또는 편집 중인 텍스트 크기를 조절합니다. |
| Shift+드래그 | 선·화살표를 45도 간격에 맞추고, 사각형·타원을 정사각형·원으로 그립니다. |

## 텍스트 편집

| 입력 대상 | 키 | 동작 |
| --- | --- | --- |
| 화면 텍스트 | Enter / Shift+Enter / 입력창 밖 클릭 | 확정 / 줄바꿈 / 확정 후 다음 텍스트 위치 선택 |
| 노트 메모 | Enter / Ctrl+Enter | 줄바꿈 / 내용을 보존하며 편집 마침 |
| 노트 메모 | Alt+휠 | 메모를 위아래로 스크롤합니다. |

**설정 → 단축키**에서 조합을 바꿀 수 있습니다. 일반 키 변경은 **일반 설정 저장**으로 저장합니다. 화면 액자 단축키는 새 조합을 누른 뒤 입력칸을 벗어나면 자동 저장됩니다. 다른 앱에서 Ctrl+F4를 자주 쓴다면 ArcDraw에서 화면 액자 키를 바꿀 수 있습니다.
