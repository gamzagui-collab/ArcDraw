## 화면 위에 쓰고 그리기

1. 맞는 ZIP을 모두 풀고 **ArcDraw.exe**를 실행합니다. 화면의 ArcDraw 아이콘 또는 **Ctrl+Alt+G**로 툴바를 엽니다.
2. **Caps Lock**을 켜고 펜, 형광펜 프리셋, 직선, 도형, 화살표 등의 도구를 선택해 화면 위에 그립니다. 텍스트를 쓰려면 **T**를 누르고 화면을 클릭합니다.
3. **Caps Lock**을 끄면 화면 위의 다른 Windows 앱을 평소처럼 조작할 수 있습니다. **Esc**로 그리기 상태를 종료하면 화면의 ArcDraw 아이콘으로 돌아갑니다.

휠로 선 굵기나 편집 중인 글자 크기를 조절할 수 있습니다. 색상 단추는 현재 펜 또는 텍스트의 색을 바꾸고, **Aa**는 글꼴을 고릅니다. 숫자키의 펜 프리셋은 **설정 → 펜 프리셋**에서 바꿀 수 있습니다.

설정·노트 버튼은 도구 툴바에 붙은 한 열에 표시됩니다. 노트 이름이 잘리면 마우스를 올려 전체 이름을 확인하세요.

자유펜·직선·도형·화살표·연속선을 선택한 상태에서는 **←/→**로 빠른 색상을 오갈 수 있습니다. 툴바 색상 설정에서 빠른 색상을 최대 12개까지 추가·삭제·수정합니다. 클립아트를 선택한 상태에서는 **←/→**로 등록된 클립아트를 오갑니다. 화면 텍스트는 위치를 클릭한 뒤 바로 입력할 수 있으며 툴바 팔레트에서 글자색을 고릅니다. 텍스트 입력창 바깥을 클릭하면 입력을 끝내고, 다음 위치를 클릭하면 바로 새 텍스트를 입력합니다.

Ctrl을 누른 동안 화면에 그린 선·도형·클립아트·텍스트를 클릭해 선택할 수 있습니다. 선택한 대상을 Ctrl+드래그하면 위치가 바뀝니다.

**클립아트 관리**에서 이미지를 고르거나 파일·클립보드에서 추가할 수 있습니다. 기본 스티커 30종이 들어 있으며, 직접 추가한 이미지는 계속 사용할 수 있습니다. 클립아트를 화면에 많이 배치할수록 목록 앞쪽으로 이동합니다. 클립아트 도구의 ←/→는 현재 목록 순서로 이동합니다.

Caps Lock을 켠 채 다른 앱을 잠깐 조작하려면 마우스 **휠 버튼**을 사용하세요. 휠 버튼 클릭은 일반 왼쪽 클릭처럼 동작하고, 제목 표시줄을 휠 버튼으로 잡아 끌면 창을 옮길 수 있습니다. 툴바의 **잠금 아이콘**을 열면 툴바 가장자리나 모서리를 끌어 크기를 바꿀 수 있습니다. 크기 조절 중에는 화면 그리기가 멈춥니다. **설정 → 테마 → 주제별 테마 전체 보기**에서는 카드 위에 마우스를 올려 전체 툴바를 확대해 보고, 카드를 눌러 창을 닫지 않은 채 테마를 바로 적용합니다.

툴바 잠금 아이콘은 **Caps Lock을 켠 상태에서도** 누를 수 있습니다. 앱을 시작하면 자물쇠는 잠겨 있습니다. 열린 자물쇠가 표시되면 화면 중앙의 안내를 확인하고 툴바의 오른쪽·아래쪽 테두리나 오른쪽 아래 모서리를 잡아 끌어 크기를 정한 뒤 다시 눌러 잠그세요.

**설정 → 툴바**에서 가로 한 줄·두 줄 또는 세로 한 열·두 열 배치를 선택할 수 있습니다. 세로 배치에서는 도구 툴바와 설정 카드의 너비가 같습니다. 버전과 고지는 **설정 → ArcDraw 정보**에서 확인합니다.

## 화이트보드 노트

**＋ 노트**로 창을 추가하고 제목줄을 끌어 옮기거나 모서리로 크기를 바꿉니다. **T**로 메모를 쓰거나 펜과 도형 도구로 그리세요. 제목줄의 **✎**에서 이름과 글꼴을, 배경 슬라이더로 투명도를 바꿉니다.

노트 제목을 눌러 선택하고 옆의 **● / □**로 표시를 전환합니다. Caps Lock을 끄면 노트들이 잠시 숨고, 다시 켜면 개별 표시 상태가 복원됩니다. 이름, 메모, 필기, 위치, 크기, 글꼴은 자동 저장되며 다시 실행한 뒤 그리기를 켜면 복원합니다. 삭제한 노트는 **＋ 노트** 옆 **복구**에서 찾을 수 있습니다.

## 헤드라인

툴바의 **＋ 헤드라인**을 누르면 발표 제목이나 자막을 띄울 수 있습니다. 헤드라인 위에 마우스를 올리면 제목줄이 나타납니다. 여기서 **모양**, **테두리**, **배경**을 고릅니다. 모양 목록에서 즐겨찾기와 최근에 고른 디자인을 확인할 수 있습니다.

## 화면 액자

툴바나 Windows 트레이 메뉴에서 **화면 액자**를 열고 **화면 액자 표시**를 켭니다. 테마를 이름이나 번호로 찾아 미리 보고, 대상 화면, 안쪽 폭, 불투명도를 조절할 수 있습니다. 액자는 가운데가 투명하며 클릭이 뒤의 앱에 전달됩니다.

- **전체 액자**에 내장 액자 150종이 있습니다. 왼쪽에서 컬러팝, 설원, 판타지 장식, 귀여운 액자 등 15개 분류를 고르거나 전체 목록에서 001~150번 또는 이름으로 검색할 수 있습니다. 원본 비율은 16:9입니다.
- **테두리 폭**은 화면 가장자리를 기준으로 안쪽으로 차지하는 폭을 80~120%에서 조절합니다. 100%는 원본입니다. **작업 영역 여백**은 일반 창이 최대화되는 범위를 조절합니다.
- **바깥쪽 이동**은 액자 사진을 화면 중앙에서 확대해 각 가장자리를 0~-50%까지 화면 밖으로 보냅니다. 밖으로 나간 부분은 잘리므로 화면 끝에 닿지 않는 장식을 맞출 때 사용하세요.
- SVG 액자를 처음 적용하면 **인코딩 중**이 표시됩니다. **전체 인코딩**은 현재 액자 표시 영역에 맞춰 내장 SVG 140종을 한 번에 준비합니다. 취소하고 다시 시작해도 완료된 파일은 재사용합니다. PNG는 실행 폴더의 `screen-frame-images/.png-cache`에 남으며 다른 크기의 표시 영역에는 별도로 변환합니다.
- **AI 제작 프롬프트 복사하기**에서 주제, 가로·세로 해상도, 제작 개수(1~10개, 기본 10개)와 추가 요청사항을 입력하세요. 게임 화면 스크린샷(PNG/JPEG)을 불러오면 그 사진을 가상 화면 배경으로 삼아 지도·채팅창·버튼 위에 장식 최소화 영역을 드래그로 표시할 수 있습니다. 사진을 불러오면 해상도도 사진 크기로 맞춰집니다. 우클릭은 영역 하나를 지웁니다. 사진은 로컬 미리보기에만 쓰이고 복사한 프롬프트에는 좌표만 들어갑니다. AI가 사진 자체도 보아야 한다면 직접 별도로 첨부하세요.
- 테마 카드 위에 포인터를 올리면 확대 미리보기가 표시됩니다. 카드를 누르면 선택 창을 열어 둔 채 화면에 바로 적용됩니다.
- **Ctrl+F4**는 툴바가 닫혀 있어도 액자를 켜고 끕니다. 키는 **설정 → 단축키 → 화면 액자 켜기/끄기 (전역)**에서 바꿉니다.
- **단축키 로고 보이기**는 액자가 켜졌을 때 화면 상단 중앙에 현재 종료 단축키를 표시합니다.
- **작업 영역 자동 확보**를 켜면 일반 창을 액자 안쪽까지 최대화할 수 있습니다. 액자를 끄면 예약된 영역을 해제합니다.
- 브라우저 전체화면에서도 액자가 표시됩니다. 다른 앱의 전체화면에 대해서는 **게임 등 전체화면에서도 액자 표시**를 사용하세요. 독점 전체화면에서 액자가 보이지 않는 게임은 테두리 없는 창 모드로 바꿔 보세요.

### 내 액자 추가

**화면 액자 → 테마 → + 내 액자 추가**를 누르고 파일을 고릅니다. Ctrl 또는 Shift로 SVG, PNG, JPEG 파일을 여러 개 선택할 수 있습니다. 열 수 없는 파일은 한 번에 알려 주며 나머지는 계속 추가합니다. 추가한 파일은 **내 액자** 목록에 표시됩니다. 계속 표시하려면 **화면 액자 표시**를 켭니다.

- **SVG**는 가운데를 투명하게 두고, 글자를 패스로 바꾸고, 사용한 PNG나 JPEG는 SVG 안에 포함하세요. 화면 크기에 맞춰 투명 PNG를 생성합니다.
- **PNG**는 가운데를 투명하게 저장하세요. 화면 픽셀 해상도와 같을 때 가장 선명합니다.
- **JPEG (.jpg, .jpeg)**는 가운데를 장식과 색이 다른 단색으로 채우세요. 앱이 그 배경을 제거하고 투명 PNG로 저장합니다.

이미지 파일은 64MB 이하로 저장하세요. PNG와 JPEG는 각 변 8192px 이하, 전체 4000만 픽셀 이하를 지원합니다. 액자 비율이 화면과 다르면 그림 전체가 보이도록 맞추므로 여백이 생길 수 있습니다. **영역 여백**은 일반 창의 최대화 영역을 조절합니다. 새 폴더에 수동 설치할 때는 개인 설정과 함께 `screen-frame-images` 폴더를 옮기면 내 액자를 다시 사용할 수 있습니다.

## 업데이트와 이전 버전

트레이의 **업데이트 확인…**으로 새 버전을 받을 수 있습니다. 수동으로 설치하려면 [릴리스 목록](https://github.com/gamzagui-collab/ArcDraw/releases)에서 원하는 버전의 ZIP을 새 폴더에 풀고 그 폴더에서 실행하세요. 설정과 노트 파일은 기존 실행 폴더에 남아 있을 수 있으므로, 폴더를 삭제하기 전에 필요한 파일을 백업하세요.

설치 폴더에 쓸 수 없는 환경에서는 설정과 필기를 `%APPDATA%\ArcDraw`에 저장합니다. 이전 버전의 `%APPDATA%\ppInk` 데이터가 있으면 첫 실행 때 새 폴더로 복사하며, 이전 폴더는 복구용으로 남겨 둡니다. 원 프로젝트의 저작권 표기는 **ArcDraw · 개발 및 라이선스**에 보존됩니다.
