# ArcDraw 설정

노트 목록의 **⚙ 설정**을 눌러 엽니다. 각 탭에서 저장/적용 버튼을 눌러야 반영됩니다.

## 펜 프리셋

1. 저장할 숫자키 슬롯을 선택합니다. 기존 키 배치는 바꾸지 않으며 목록에 실제 단축키가 표시됩니다.
2. 이름·색·불투명도·굵기·펜촉·화면 도구·채움·선 모양을 정합니다. **현재 도구 가져오기**로 현재 펜/도구를 가져올 수도 있습니다.
3. **프리셋 저장**을 누릅니다. CAPS ON에서 목록에 표시된 키로 호출합니다.

지원 화면 도구는 자유펜·직선·사각형·원/타원·시작/끝 화살표·연속선입니다. 도형과 점선 프리셋은 화면 도구에 적용되며, 노트는 기존 독립 펜 입력을 유지합니다. 저장 후 임시로 도구를 바꾸더라도 프리셋은 별도 저장 버튼을 누르기 전까지 유지됩니다. 의도적으로 동일 키를 공유하는 기존 펜은 원래 순환 동작을 유지합니다. 텍스트 편집·설정 창·CAPS OFF에서는 프리셋 키를 가로채지 않습니다.

## 글꼴

**글꼴 선택…**에서 글꼴·크기·스타일을 정하고 **글꼴 저장**을 누릅니다. 이후 생성하는 화면/노트 텍스트의 기본값이 됩니다. 기본 노트 글꼴은 맑은 고딕입니다.

설정 창을 열기 전에 노트를 선택했다면 **선택한 노트의 기존 글자에도 적용**을 체크할 수 있습니다. 해당 노트의 기존 글자만 바꾸며 위치/색은 유지합니다. 이 변경은 노트 실행 취소에 포함됩니다. 화면의 기존 글자는 바꾸지 않습니다.

## 툴바와 노트

툴바 탭에서 기존 10개 테마·크기·가로 1줄/2줄·세로 배치를 고릅니다.

CAPS ON: Delete 실행 취소 / Ctrl+Delete 선택 대상 전체 삭제 / Ctrl+Shift+Z 다시 실행. 화면 또는 노트를 먼저 선택하세요. 텍스트 편집 중에는 일반 편집 키로 동작합니다. Shift+Delete는 ArcDraw 전체 삭제가 아닙니다.

ESC는 노트를 숨기고 아이콘으로 돌아갑니다. 앱이 계속 실행되는 동안 다시 그리기를 켜면 같은 내용·위치가 복원됩니다. 완전 종료 후 노트를 자동 저장하는 기능은 추가하지 않았습니다.

## 설정 파일

프리셋·글꼴은 실행 폴더의 `drawing-settings.xml`에 저장됩니다. 다음 저장에서 이전 파일을 `.bak`으로 보관하며 잘못된 파일은 백업 읽기를 시도합니다. 기존 `pens.ini`, `hotkeys.ini`, `config.ini`는 이 설정 창에서 덮어쓰지 않습니다. 개인 설정·필기는 공개 ZIP에 포함되지 않습니다.
