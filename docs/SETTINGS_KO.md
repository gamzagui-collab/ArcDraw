# ArcDraw 설정

노트 목록의 **⚙ 설정**을 눌러 엽니다. 각 탭에서 저장/적용 버튼을 눌러야 반영됩니다.

## 펜 프리셋

1. 저장할 숫자키 슬롯을 선택합니다. 기존 키 배치는 바꾸지 않으며 목록에 실제 단축키가 표시됩니다.
2. 이름·색·불투명도·굵기·펜촉·도구·채움·선 모양을 정합니다. **현재 도구 가져오기**로 현재 펜/도구를 가져올 수도 있습니다.
3. **프리셋 저장**을 누릅니다. CAPS ON에서 목록에 표시된 키로 호출합니다.

지원 도구는 자유펜·직선·사각형·원/타원·시작/끝 화살표·연속선입니다. 노트에서도 같은 도형·채움·선 모양 프리셋을 사용합니다. 일반 자유펜·지우개는 기존 독립 Ink 입력을 유지합니다. 노트 연속선은 이어 클릭/드래그하며 우클릭으로 마칩니다. 다른 프리셋으로 바꾸면 기존 선은 그대로 두고 새 연속선을 시작합니다. 저장 후 임시로 도구를 바꾸더라도 프리셋은 별도 저장 버튼을 누르기 전까지 유지됩니다. 의도적으로 동일 키를 공유하는 기존 펜은 원래 순환 동작을 유지합니다. 텍스트 편집·설정 창·CAPS OFF에서는 프리셋 키를 가로채지 않습니다.

## 글꼴

**글꼴 선택…**에서 글꼴·크기·스타일을 정하고 **글꼴 저장**을 누릅니다. 이후 생성하는 화면 T와 기존 방식의 배치 글자에 적용합니다. 노트 메모 속성은 제목 ✎에서 별도로 정하며 기본값은 맑은 고딕 17pt/어두운 글자색입니다.

설정 창을 열기 전에 노트를 선택했다면 **선택한 노트의 기존 배치 글자에도 적용 (메모 제외)**을 체크할 수 있습니다. 해당 노트의 기존 배치 글자만 바꾸며 위치/색은 유지합니다. 노트 메모는 바꾸지 않습니다. 이 변경은 노트 실행 취소에 포함됩니다. 화면의 기존 글자는 바꾸지 않습니다.

## 툴바와 노트

툴바 탭에서 기존 10개 테마·크기·가로 1줄/2줄·세로 배치를 고릅니다.

CAPS ON: Delete 실행 취소 / Ctrl+Delete 선택 대상 전체 삭제 / Ctrl+Shift+Z 다시 실행. 화면 또는 노트를 먼저 선택하세요. 텍스트 편집 중에는 일반 편집 키로 동작합니다. Shift+Delete는 ArcDraw 전체 삭제가 아닙니다.

ESC는 노트를 숨기고 아이콘으로 돌아갑니다. 앱이 계속 실행되는 동안 다시 그리기를 켜면 같은 내용·위치가 복원됩니다. 완전히 종료해도 노트가 자동저장되며 다음 실행에서 그리기를 켜면 복원합니다.

## 설정 파일

프리셋·글꼴은 실행 폴더의 `drawing-settings.xml`에 저장됩니다. 다음 저장에서 이전 파일을 `.bak`으로 보관하며 잘못된 파일은 백업 읽기를 시도합니다. 기존 `pens.ini`, `hotkeys.ini`, `config.ini`는 이 설정 창에서 덮어쓰지 않습니다. 개인 설정·필기는 공개 ZIP에 포함되지 않습니다.

## 노트 정렬

노트 카드의 **세로 정렬**는 생성 순서대로 위에서 아래로 배치하고 다음 열로 넘어갑니다. **가로 정렬**는 왼쪽에서 오른쪽으로 배치하고 다음 행으로 넘어갑니다. 현재 툴바가 있는 화면의 작업 영역을 사용합니다.

표시 중인 노트만 정렬하며 숨긴 노트는 그대로 둡니다. 크기와 내용은 유지합니다. 공간이 부족하면 안내하고 기존 위치를 유지하므로 일부 노트를 숨기거나 크기를 줄인 뒤 다시 시도하세요.

## 필기 대상 네온과 Alt+Tab

CAPS ON에서 현재 필기 대상에만 얇은 네온 테두리를 표시합니다. 화면을 선택하면 화면에, 노트를 클릭하거나 필기하면 그 노트에 표시합니다. 노트를 이동하거나 크기를 바꾸어도 따라갑니다. CAPS OFF와 그리기 종료에서는 숨깁니다.

Alt를 누른 채 Tab을 여러 번 눌러 화면/노트 목록을 순환하고 Alt를 놓아 확정합니다. Esc는 대상을 바꾸지 않고 전환 목록을 취소합니다. 숨긴 노트는 숨김 표시로 나열하며 확정하면 다시 표시합니다. 생성 순서대로 순환합니다.

CAPS ON에서는 메모 편집 중에도 메모를 확정한 뒤 화면·노트 전환 목록을 엽니다. 설정/기존 화면 입력 대화상자와 CAPS OFF에서는 Windows Alt+Tab을 사용합니다. 설정 창을 열거나 그리기를 종료하면 보류 중인 선택은 취소됩니다. Alt만 누르고 있으면 기존 도구별 단축키 안내를 보여줍니다.

## 노트 이름과 메모장 입력

제목 옆 **✎** 또는 제목/툴바 목록 우클릭 → **이름·메모 글꼴 설정…**에서 이름과 해당 노트 메모의 글꼴·크기·색상·굵게/기울임을 바꿉니다. 미리보기를 보고 **적용**하며 **취소/Esc**는 변경하지 않습니다. 메모 속성은 다른 노트 및 화면 T 도구와 별개입니다. 최대 40자이며 제목·목록·Alt+Tab에 같은 이름을 표시합니다. 이름 변경은 필기 실행 취소와 별개입니다.

노트를 선택하고 **T**를 고르면 좌측 상단부터 노트 전체에 메모합니다. **Enter는 줄바꿈**이며 선택·복사·붙여넣기·기본 텍스트 편집과 세로 스크롤을 사용합니다. 펜 버튼을 누르면 메모를 확정하고 필기를 계속합니다. 메모의 **Ctrl+Enter**는 내용을 유지하며 편집을 마칩니다. **Esc**는 내용을 확정해 보존하고 노트를 숨긴 뒤 앱 아이콘으로 돌아갑니다. CAPS ON/OFF 모두 동작하며 설정 대화상자의 Esc는 적용 없이 취소합니다. CAPS OFF에서도 메모를 먼저 확정합니다.

이전에 위치를 지정해 배치한 글자는 삭제하거나 합치지 않습니다. 제목을 우클릭하여 **기존 배치 글자 편집**에서 고릅니다. 해당 배치 글자 편집 중에도 Esc는 현재 내용을 유지한 채 앱 아이콘으로 돌아갑니다.

이름·메모·필기·위치·개별 글꼴과 표시 상태는 자동저장하며 앱을 완전히 종료했다가 다시 실행해도 복원합니다.

## 노트 목록과 표시·숨김

노트는 접기 메뉴 없이 모두 나열합니다. **노트 이름은 선택 버튼**입니다. 오른쪽 **● / □** 버튼으로 표시·숨김을 전환하며 **×**는 그 노트만 삭제합니다. 숨긴 노트는 이름 앞 **○**로 표시합니다. 숨긴 노트의 이름을 누르면 표시하고 선택합니다. 노트 안을 클릭하거나 Alt+Tab으로 고르면 해당 노트를 선택합니다.

**CAPS OFF**에서는 모든 노트를 잠시 숨깁니다. **ON**으로 켜면 직전에 표시되던 노트를 복원합니다. 표시·숨김 버튼으로 개별 숨긴 노트는 계속 숨김을 유지하며, 이름과 내용은 남습니다. OFF 중 생성한 노트도 ON에서 표시됩니다.

세로 툴바 아래가 부족하면 목록 카드를 툴바 옆에 놓고, 목록 높이 자체가 부족하면 다음 열로 이어집니다. 화면 너비까지 부족한 경우 가로 스크롤을 사용합니다.

## 노트 자동저장

실행 설정 폴더의 **ArcDraw.notes.xml**에 노트 생성 순서·이름·메모/배치 글자·필기·위치·크기·글꼴·색상·개별 숨김 상태를 저장합니다. 입력이 잠시 멈췄을 때와 지속 입력 중 주기적으로 저장하며 정상 종료 때 마지막 입력을 확정합니다. 앱을 다시 실행한 뒤 그리기를 켜면 노트가 복원됩니다. CAPS OFF에서는 복원된 노트도 숨긴 상태를 유지합니다.

임시 파일을 완성한 뒤 교체하며 직전 파일은 **ArcDraw.notes.xml.bak**에 남습니다. 원본을 읽지 못하면 백업을 시도합니다. 읽지 못한 원본은 다음 저장 때 **.unreadable_** 파일로 보존합니다. 저장이 실패하면 이전 저장본을 유지하고 트레이 알림을 표시합니다. 저장 파일은 개인 데이터이며 공개 ZIP/Git에 포함하지 않습니다.

삭제한 노트도 저장 상태에 반영하므로 다음 시작에서 재등장하지 않습니다. 종료 전 실행 취소 기록 전체는 저장하지 않습니다.

## 메모에서 화면 필기로 전환

노트 메모를 쓰다가 노트 밖 화면을 바로 드래그하면 메모 내용을 확정하고 직전 화면 그리기 도구로 돌아갑니다. 메모 모드를 유지한 노트를 목록/종이로 다시 선택하면 메모를 이어 씁니다. 제목의 이름 영역이나 빈 곳을 클릭/드래그하면 메모를 확정하고 편집을 끝냅니다. 그 뒤에는 단축키를 사용하며, 다시 입력할 때는 T를 누릅니다. 노트에서 펜이나 도형을 사용하려면 툴바에서 해당 도구를 고르세요.

화면 텍스트 입력은 화면을 선택한 뒤 **T**를 고릅니다. 노트 메모의 T가 화면 드래그를 텍스트 입력으로 바꾸지 않도록 구분합니다. 창이 자동으로 활성화되는 것만으로 필기 대상이 바뀌지 않으며 실제 클릭/목록/Alt+Tab으로 선택합니다.

제목 표시줄 클릭으로 편집을 끝내도 노트 선택·내용·이동은 유지됩니다. 제목의 ✎ 설정 버튼과 × 삭제 버튼은 기존 기능 그대로입니다.
