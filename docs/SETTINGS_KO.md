# ArcDraw 설정

노트 목록의 **⚙ 설정**을 눌러 엽니다. 각 탭에서 저장/적용 버튼을 눌러야 반영됩니다.

## 펜 프리셋

1. 저장할 숫자키 슬롯을 선택합니다. 기존 키 배치는 바꾸지 않으며 목록에 실제 단축키가 표시됩니다.
2. 이름·색·불투명도·굵기·펜촉·도구·채움·선 모양을 정합니다. **현재 도구 가져오기**로 현재 펜/도구를 가져올 수도 있습니다.
3. **프리셋 저장**을 누릅니다. CAPS ON에서 목록에 표시된 키로 호출합니다.

지원 도구는 자유펜·직선·사각형·원/타원·시작/끝 화살표·연속선입니다. 노트에서도 같은 도형·채움·선 모양 프리셋을 사용합니다. 일반 자유펜·지우개는 기존 독립 Ink 입력을 유지합니다. 노트 연속선은 이어 클릭/드래그하며 우클릭으로 마칩니다. 다른 프리셋으로 바꾸면 기존 선은 그대로 두고 새 연속선을 시작합니다. 저장 후 임시로 도구를 바꾸더라도 프리셋은 별도 저장 버튼을 누르기 전까지 유지됩니다. 의도적으로 동일 키를 공유하는 기존 펜은 원래 순환 동작을 유지합니다. 텍스트 편집·설정 창·CAPS OFF에서는 프리셋 키를 가로채지 않습니다.

## 글꼴

**글꼴 선택…**에서 글꼴·크기·스타일을 정하고 **글꼴 저장**을 누릅니다. 이후 생성하는 화면 T와 기존 방식의 배치 글자에 적용합니다. 노트 메모 속성은 제목 ✎에서 별도로 정하며 기본값은 맑은 고딕 17pt/어두운 글자색입니다.

설정 창을 열기 전에 노트를 선택했다면 **선택한 노트의 기존 배치 글자에도 적용 (메모 제외)**을 체크할 수 있습니다. 해당 노트의 기존 배치 글자만 바꾸며 위치/색은 유지합니다. 노트 메모는 바꾸지 않습니다. 글자 속성은 글꼴 설정에서 다시 조정하며 그리기 실행 취소는 필기에만 적용합니다. 화면의 기존 글자는 바꾸지 않습니다.

## 툴바와 노트

툴바 탭에서 기존 10개 테마·크기·가로 1줄/2줄·세로 배치를 고릅니다.

CAPS ON: Delete 실행 취소 / Ctrl+Delete 전체 지우기(노트는 필기만) / Ctrl+Shift+Z 다시 실행. 화면 또는 노트를 먼저 선택하세요. 텍스트 편집 중에는 일반 편집 키로 동작합니다. Shift+Delete는 ArcDraw 전체 삭제가 아닙니다.

ESC는 노트를 숨기고 아이콘으로 돌아갑니다. 앱이 계속 실행되는 동안 다시 그리기를 켜면 같은 내용·위치가 복원됩니다. 완전히 종료해도 노트가 자동저장되며 다음 실행에서 그리기를 켜면 복원합니다.

## 설정 파일

프리셋·글꼴은 실행 폴더의 `drawing-settings.xml`에 저장됩니다. 다음 저장에서 이전 파일을 `.bak`으로 보관하며 잘못된 파일은 백업 읽기를 시도합니다. 기존 `pens.ini`, `hotkeys.ini`, `config.ini`는 이 설정 창에서 덮어쓰지 않습니다. 개인 설정·필기는 공개 ZIP에 포함되지 않습니다.

## 노트 정렬

노트 카드의 **세로 정렬**는 생성 순서대로 위에서 아래로 배치하고 다음 열로 넘어갑니다. **가로 정렬**는 왼쪽에서 오른쪽으로 배치하고 다음 행으로 넘어갑니다. 현재 툴바가 있는 화면의 작업 영역을 사용합니다.

표시 중인 노트만 정렬하며 숨긴 노트는 그대로 둡니다. 크기와 내용은 유지합니다. 공간이 부족하면 안내하고 기존 위치를 유지하므로 일부 노트를 숨기거나 크기를 줄인 뒤 다시 시도하세요.

## 필기 대상 네온과 Alt+Tab

CAPS ON에서 현재 필기 대상에만 12px 네온 테두리를 표시합니다(기존 4px의 3배). 화면을 선택하면 화면에, 노트를 클릭하거나 필기하면 그 노트에 표시합니다. 노트를 이동하거나 크기를 바꾸어도 따라갑니다. CAPS OFF와 그리기 종료에서는 숨깁니다.

Alt를 누른 채 Tab을 여러 번 눌러 화면/노트 목록을 순환하고 Alt를 놓아 확정합니다. Esc는 대상을 바꾸지 않고 전환 목록을 취소합니다. 숨긴 노트는 숨김 표시로 나열하며 확정하면 다시 표시합니다. 생성 순서대로 순환합니다.

CAPS ON에서는 메모 편집 중에도 메모를 확정한 뒤 화면·노트 전환 목록을 엽니다. 설정/기존 화면 입력 대화상자와 CAPS OFF에서는 Windows Alt+Tab을 사용합니다. 설정 창을 열거나 그리기를 종료하면 보류 중인 선택은 취소됩니다. Alt만 누르고 있으면 기존 도구별 단축키 안내를 보여줍니다.

## 노트 이름과 메모장 입력

제목 옆 **✎** 또는 제목/툴바 목록 우클릭 → **이름·메모 글꼴 설정…**에서 이름과 해당 노트 메모의 글꼴·크기·색상·굵게/기울임을 바꿉니다. 미리보기를 보고 **적용**하며 **취소/Esc**는 변경하지 않습니다. 메모 속성은 다른 노트 및 화면 T 도구와 별개입니다. 최대 40자이며 제목·목록·Alt+Tab에 같은 이름을 표시합니다. 이름 변경은 필기 실행 취소와 별개입니다.

노트를 선택하고 **T**를 고르면 좌측 상단부터 노트 전체에 메모합니다. **Enter는 줄바꿈**이며 선택·복사·붙여넣기·기본 텍스트 편집과 세로 스크롤을 사용합니다. 펜 버튼을 누르면 메모를 확정하고 필기를 계속합니다. 메모의 **Ctrl+Enter**는 내용을 유지하며 편집을 마칩니다. **Esc**는 내용을 확정해 보존하고 노트를 숨긴 뒤 앱 아이콘으로 돌아갑니다. 설정 대화상자의 Esc는 적용 없이 취소합니다. CAPS OFF로 전환할 때도 메모를 먼저 확정합니다.

이전에 위치를 지정해 배치한 글자는 삭제하거나 합치지 않습니다. 제목을 우클릭하여 **기존 배치 글자 편집**에서 고릅니다. 해당 배치 글자 편집 중에도 Esc는 현재 내용을 유지한 채 앱 아이콘으로 돌아갑니다.

이름·메모·필기·위치·개별 글꼴과 표시 상태는 자동저장하며 앱을 완전히 종료했다가 다시 실행해도 복원합니다.

## 노트 목록과 표시·숨김

노트는 접기 메뉴 없이 모두 나열합니다. **노트 이름은 선택 버튼**입니다. 오른쪽 **● / □** 버튼으로 표시·숨김을 전환하며 **×**는 그 노트만 삭제합니다. 숨긴 노트는 이름 앞 **○**로 표시합니다. 숨긴 노트의 이름을 누르면 표시하고 선택합니다. 노트 안을 클릭하거나 Alt+Tab으로 고르면 해당 노트를 선택합니다.

**CAPS OFF**에서는 모든 노트를 잠시 숨깁니다. **ON**으로 켜면 직전에 표시되던 노트를 복원합니다. 표시·숨김 버튼으로 개별 숨긴 노트는 계속 숨김을 유지하며, 이름과 내용은 남습니다. OFF 중 생성한 노트도 ON에서 표시됩니다.

세로 툴바 아래가 부족하면 목록 카드를 툴바 옆에 놓고, 목록 높이 자체가 부족하면 다음 열로 이어집니다. 화면 너비까지 부족한 경우 가로 스크롤을 사용합니다.

## 노트 자동저장

실행 설정 폴더의 **ArcDraw.notes.xml**에 노트 생성 순서·이름·메모/배치 글자·필기·위치·크기·글꼴·색상·개별 숨김 상태를 저장합니다. 입력이 잠시 멈췄을 때와 지속 입력 중 주기적으로 저장하며 정상 종료 때 마지막 입력을 확정합니다. 앱을 다시 실행한 뒤 그리기를 켜면 노트가 복원됩니다. CAPS OFF에서는 복원된 노트도 숨긴 상태를 유지합니다.

임시 파일을 완성한 뒤 교체하며 직전 파일은 **ArcDraw.notes.xml.bak**에 남습니다. 원본을 읽지 못하면 백업을 시도합니다. 읽지 못한 원본은 다음 저장 때 **.unreadable_** 파일로 보존합니다. 저장이 실패하면 이전 저장본을 유지하고 트레이 알림을 표시합니다. 저장 파일은 개인 데이터이며 공개 ZIP/Git에 포함하지 않습니다.

삭제한 노트도 저장 상태에 반영하므로 다음 시작에서 재등장하지 않습니다. 종료 전 실행 취소 기록 전체는 저장하지 않습니다.

## 메모에서 화면 필기로 전환

노트 메모를 쓰다가 노트 밖 화면을 바로 드래그하면 메모 내용을 확정하고 직전 화면 그리기 도구로 돌아갑니다. 메모 모드를 유지한 노트를 목록/종이로 다시 선택하면 메모를 이어 씁니다. 제목의 이름 영역이나 빈 곳을 클릭/드래그하면 메모를 확정하고 편집을 끝냅니다. 그 뒤에는 단축키를 사용하며, 본문을 클릭하면 T 없이 메모를 이어 씁니다. 직접 펜/그리기 도구를 선택한 경우에는 본문에서 그리기를 유지합니다. T로 다시 입력할 수도 있습니다. 노트에서 펜이나 도형을 사용하려면 툴바에서 해당 도구를 고르세요.

화면 텍스트 입력은 화면을 선택한 뒤 **T**를 고릅니다. 노트 메모의 T가 화면 드래그를 텍스트 입력으로 바꾸지 않도록 구분합니다. 창이 자동으로 활성화되는 것만으로 필기 대상이 바뀌지 않으며 실제 클릭/목록/Alt+Tab으로 선택합니다.

제목 표시줄 클릭으로 편집을 끝내도 노트 선택·내용·이동은 유지됩니다. 제목의 ✎ 설정 버튼과 × 삭제 버튼은 기존 기능 그대로입니다.

제목 클릭으로 잠시 멈춘 메모와 직접 펜을 고른 상태를 구분합니다. 메모 재개용 본문 클릭이 펜 점으로 저장되지 않으며, 자유펜/팔레트 펜을 직접 선택하면 메모 자동 재개를 해제합니다.

## 삭제 확인과 텍스트 보호

노트 제목/목록의 **X**는 노트 자체 삭제입니다. 해당 이름과 메모·필기 삭제 문구를 확인한 뒤 **삭제**를 선택해야 진행합니다. 기본 선택은 **취소**이며 **Esc**로도 취소합니다. 브리핑 중 잠시 감추려면 **●/□ 표시·숨김**을 사용하세요.

노트 **전체 지우기(Ctrl+Delete)**와 지우개는 필기만 지우며 글자는 유지합니다. 노트의 그리기 실행 취소/다시 실행도 현재 글자를 삭제하거나 되살리지 않습니다. 글자는 편집창에서 **Ctrl+A → Delete** 등으로 수정·삭제하고, 텍스트 실행 취소는 편집기에서 합니다.

화면 T로 만든 텍스트를 포함한 **화면 전체 지우기**와 **지우개 텍스트 삭제**도 확인창을 띄웁니다. 취소하면 보존하며 삭제를 선택해야 지워집니다. 일반 필기만 지우는 경우에는 이 확인창이 반복되지 않습니다. 기존 화면 ESC 초기화와 전체 화면 실행 취소 동작은 유지합니다.

## 삭제한 노트 복구

v0.30에서 노트 X로 삭제한 뒤에는 툴바 **＋ 노트** 옆 **복구**를 열고 노트 이름과 삭제 시각을 확인한 뒤 **복구**를 누르세요. 메모·필기, 이름·글꼴 설정, 위치·크기, 개별 표시 상태가 되살아납니다. 화면 배치가 바뀌어 제목이 화면 밖에 있으면 현재 화면에서 접근할 수 있게 위치를 조정합니다. 복구한 항목은 목록에서 빠집니다.

삭제한 노트 목록은 활성 노트와 함께 실행 설정 폴더의 `ArcDraw.notes.xml`에 저장합니다. 앱을 껐다 켜도 목록이 남습니다.

## 복구 목록 영구 삭제

복구 목록에서 필요 없는 노트를 선택하고 **영구 삭제**를 누르세요. 확인창에 노트 이름과 복구할 수 없다는 안내가 표시됩니다. 취소하면 목록에 남습니다. 확인하면 해당 노트가 목록과 앱의 자동저장 백업에서 제거됩니다.

## CAPS OFF에서 Esc

다른 앱이 활성화된 CAPS OFF 상태에서 **Esc**는 그 앱으로 전달됩니다. ArcDraw를 실행 아이콘으로 접으려면 CAPS ON에서 Esc를 누르거나 툴바의 종료 버튼을 사용하세요.

## 그리기 커서 테두리

화면과 노트에서 그릴 때 청록색 원이 클릭 지점에 고정되어 포인터와 함께 움직입니다.

## 화면 T 입력 키

화면 T 입력창에서 **Enter**로 확정, **Shift+Enter**로 줄바꿈, **Space**로 공백을 넣습니다. 확정 후 화면의 다음 위치를 클릭하면 새 텍스트를 작성할 수 있습니다.

한글 조합 중에도 화면 T에서 **Enter**로 확정하거나 **Shift+Enter**로 줄을 바꾸면 마지막 글자까지 반영합니다.

## 공용 색상, 펜과 화면 텍스트

툴바에서 색상을 고르면 자유펜과 새 화면 텍스트가 해당 색을 사용합니다. 펜 옆 선 견본은 굵기·불투명도·펜촉·선 모양 설정을 엽니다. 프리셋 목록은 실제 선 견본과 굵기·불투명도를 보여줍니다.

화면 T 입력창에서 글꼴·크기·색상을 바꾸면 현재 객체에 즉시 적용됩니다. Shift+Enter로 새 줄을 만들면 글자를 쓰기 전부터 입력창 높이가 늘어납니다.

## 공용 크기 슬라이더

툴바 옆 세로 슬라이더로 펜·도형 굵기(px), 화면 T와 노트 메모의 글자 크기(pt)를 조절합니다. 노트에 글을 쓰는 동안 드래그하면 해당 노트에 즉시 적용되고 크기가 자동저장됩니다.

## 펜·텍스트 공용 색상

메인 툴바의 색상 버튼 하나로 펜, 화면 텍스트, 편집 중인 노트의 색을 고릅니다. 펜과 화면 텍스트는 각각 마지막으로 고른 색을 기억하며, 노트는 노트별로 글자색을 자동저장합니다.

## 툴바 글꼴 선택

화면 T를 선택하거나 노트 메모를 편집할 때 메인 툴바의 Aa 버튼으로 글꼴을 고릅니다. 작성 중인 글에 바로 적용되고, 화면 텍스트와 각 노트는 선택한 글꼴을 따로 기억합니다.

## 글꼴 검색과 미리보기

메인 툴바의 Aa를 누르고 글꼴 이름을 일부 입력하면 목록이 좁혀집니다. 각 항목에는 그 글꼴로 표시한 한글·영문·숫자 예문이 나옵니다. 항목을 누르면 적용되고 Esc를 누르면 목록이 닫힙니다.

## 글꼴 즐겨찾기

Aa 글꼴 목록에서 이름 옆 별표를 누르면 즐겨찾기에 추가됩니다. 즐겨찾기는 목록과 검색 결과의 맨 위에 표시되며 앱을 다시 열어도 유지됩니다. 채워진 별표를 다시 누르면 해제됩니다.

## 최근 사용 글꼴

Aa 글꼴 목록의 즐겨찾기 아래에 최근 선택한 글꼴이 최신순으로 최대 5개 표시됩니다. 같은 글꼴을 다시 선택하면 최근 사용 목록의 첫 자리로 올라가며 앱을 다시 실행해도 순서가 유지됩니다.

## 노트 배경과 헤드라인

노트 제목줄의 배경 슬라이더를 왼쪽으로 옮기면 배경이 투명해집니다. 노트 목록 아래 ＋ 헤드라인으로 헤드라인을 만들고 같은 버튼으로 숨기거나 다시 표시합니다. 헤드라인 제목줄의 모양 메뉴에서 사각형, 둥근 사각형, 타원형, 밑줄형을 고르고 모서리를 끌어 크기를 바꿉니다.

## Caps Lock 입력 전환 안정화

Caps Lock을 켠 뒤 다른 프로그램에 포커스가 남아 있어도 펜, 도형, 텍스트 등 주요 그리기 단축키는 ArcDraw에서 처리합니다. 노트 메모 편집 중에는 입력 포커스를 노트로 돌리고, Caps Lock을 끄면 이전 프로그램에 포커스를 돌려줍니다.

## 헤드라인 디자인 30종

헤드라인에 마우스를 올리면 제목줄과 배경 투명도 슬라이더, 모양 버튼, 크기 조절 손잡이가 나타납니다. 마우스를 떼면 제목과 프레임만 남습니다. 모양 버튼을 누르면 30종을 미리 보고 선택할 수 있습니다. 글자는 프레임마다 배지, 리본, 밑줄을 피해 배치됩니다. 선택한 프레임과 투명도는 자동저장됩니다.

## 헤드라인 프레임 색상

헤드라인에 마우스를 올린 뒤 제목줄의 색상 버튼을 누르세요. 색을 고르면 프레임에 바로 적용되고 재실행 후에도 유지됩니다. 텍스트 색은 메인 툴바에서 따로 설정할 수 있습니다. 템플릿 기본색 버튼으로 원래 색을 되돌릴 수 있습니다.

## 헤드라인 카탈로그 120종과 색상 분리

헤드라인 제목줄의 테두리와 배경 버튼으로 두 색을 각각 변경할 수 있습니다. 선택한 색은 즉시 표시되고 자동으로 저장됩니다. 템플릿 기본색을 누르면 해당 항목만 초기화됩니다. 모양 메뉴에서 기본, 모던, 캐릭터, 소품의 네 탭으로 120종을 미리 보고 고를 수 있습니다. 61–120번의 삽화는 Noto Emoji를 사용했습니다.

## 헤드라인 즐겨찾기

헤드라인 모양 메뉴에서 디자인 옆 ☆를 누르면 첫 번째 즐겨찾기 탭에 추가됩니다. ★를 다시 누르면 해제됩니다. 즐겨찾기가 있으면 모양 메뉴를 열 때 해당 탭이 먼저 표시되고, 앱을 다시 켜도 목록이 유지됩니다.

## 화면 액자와 헤드라인 최근 사용

헤드라인 모양 메뉴의 즐겨찾기 아래에 마지막으로 선택한 디자인을 최신순으로 최대 5개 표시합니다. 같은 디자인을 다시 선택하면 맨 앞으로 이동합니다. 목록과 순서는 자동 저장됩니다.

노트 툴바 또는 트레이 메뉴에서 화면 액자를 열어 표시 여부, 테마, 대상 화면을 선택할 수 있습니다. 안쪽 폭 슬라이더는 화면 바깥 위치를 유지하면서 화면 안쪽을 덮는 폭을 짧은 변의 1–12%로 조절합니다. 가운데는 투명해서 뒤에서 재생 중인 영상이나 화면이 보입니다. 첨부 시안을 참고한 10가지 가벼운 테두리 테마가 제공됩니다.

## 화면 액자 미리보기와 작업표시줄 설정

화면 액자의 테마 버튼에서 실제 테두리를 미리 보고 선택할 수 있습니다. 기존 10종과 첨부 시안에서 가져온 100종을 주제별로 제공합니다. 작업표시줄 확장을 끄면 작업 영역 가장자리에, 켜면 모니터 전체 가장자리에 그립니다. 테마와 작업표시줄 설정은 자동 저장됩니다.

## 화면 액자 즐겨찾기와 실시간 미리보기

화면 액자 테마 목록에서 ☆를 누르면 첫 번째 즐겨찾기 항목에 추가되고, ★를 다시 누르면 해제됩니다. 즐겨찾기는 앱을 다시 켜도 유지됩니다. 테마를 클릭할 때마다 창을 열어 둔 채 실제 화면에 반영합니다. 액자 표시가 꺼져 있으면 선택 창이 열려 있는 동안만 미리 보이고, 마지막으로 고른 테마는 저장됩니다.

## 화면 액자 작업 영역 자동 확보

화면 액자 표시와 작업 영역 자동 확보를 함께 켜면 선택한 모니터의 일반 창이 액자 안쪽까지만 최대화됩니다. 안쪽 폭과 불투명도를 조절할 수 있습니다. 작업 영역을 확보하는 동안은 작업표시줄을 위한 공간을 남깁니다. 액자나 작업 영역 자동 확보를 끄거나 ArcDraw를 종료하면 예약이 해제됩니다.

전체화면 앱에서 액자 숨기기는 Windows가 전체화면을 알릴 때 동작합니다. F11이나 게임 전체화면의 크기는 앱이 정합니다.

## 화면 액자 장식 복원

첨부 시안 100종의 테두리를 다시 그려 모서리 소품, 곡선, 빛 효과가 더 온전히 보이도록 했습니다. 가운데는 투명하고 안쪽 경계는 부드럽게 이어집니다. 안쪽 폭은 장식 전체의 크기를 조절하며, 작업 영역 자동 확보를 켜면 테마에 맞춰 네 방향의 여백이 조정됩니다.
